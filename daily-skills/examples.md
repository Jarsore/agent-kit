# 日报示例

## 示例 1：素材零散 → 成稿

**用户输入：**

> 今天把入库单列表的筛选修好了，和测试对了一下；库存同步接口还在联调，对方环境有问题；明天继续联调，顺便开一下盘点需求评审；小王那边的字段文档还没给到。

**输出：**

```markdown
【日报】2026-08-29（周五）

一、今日完成
1. 完成入库单列表筛选问题修复，并与测试完成一轮核对
2. 推进库存同步接口联调，定位对方测试环境异常

二、进行中 / 未完成
1. 库存同步接口联调（当前进度：约 60%；卡点：对方环境异常，待对方恢复后继续）

三、明日计划
1. 继续库存同步接口联调并验证主流程
2. 组织/参加盘点需求评审，确认范围与排期

四、问题与风险
- 库存同步依赖对方测试环境，存在联调延期风险

五、需要协助
- 需要小王提供字段文档，以便继续对接与联调
```

## 示例 2：只要更短版

**用户：** 同样内容，给领导看，再短一点。

**输出要点：**

- 保留五个章节标题  
- 每节尽量 1～2 条  
- 「进行中」合并写清进度与卡点  
- 「问题 / 协助」能一句说清就一句

## 示例 3：用户给了公司模板

**用户贴出：**

```text
今日工作：
明日计划：
备注：
```

**做法：** 不要强行套默认五段模板；按用户标题填写，把完成/进行中都归到「今日工作」，风险与协助写入「备注」。
